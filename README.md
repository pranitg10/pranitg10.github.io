# Pranit Gawade — AI, Data Science & Intelligent Automation Portfolio

**Live website:** https://pranitg10.github.io/

A responsive professional portfolio presenting Pranit's experience, technical capabilities, selected analytics projects, education, credentials, and contact links. The portfolio is also a featured project: it demonstrates how ChatGPT can support a real digital build when paired with clear direction, iterative review, and human decision-making.

## The project as an AI collaboration

This site was planned, developed, refined, and published through a multi-step collaboration with ChatGPT. The work went beyond generating a first draft: prompts and feedback shaped the content, visual direction, page structure, and implementation over several rounds.

Pranit provided the goals and portfolio information, directed each round of changes, reviewed the results, and approved the publishing steps. ChatGPT assisted with planning, front-end code edits, visual refinements, repository setup, and deployment coordination. GitHub access, public repository creation, and publication were handled through explicit permission and approval steps.

## How it was created

1. **Plan:** Define the audience, purpose, content, and structure for a job-search portfolio.
2. **Shape the design:** Refine the visual direction, typography, color palette, page hierarchy, and project presentation.
3. **Develop:** Build the site with static HTML, CSS, and JavaScript, including the profile, experience, skills, projects, education, credentials, and contact sections.
4. **Iterate:** Use targeted prompts and human review to improve the copy, layout, image sizing, mobile navigation, and project details over multiple rounds.
5. **Publish:** Connect GitHub, create the public `pranitg10.github.io` repository, add the site files, and publish from the main branch with GitHub Pages.
6. **Confirm:** Check the live deployment and verify that the portfolio and project links are available.

## Built with

- HTML5, CSS3, and vanilla JavaScript
- GitHub for source hosting and version history
- GitHub Pages for public hosting
- ChatGPT for planning support and iterative development assistance

The site has no framework or package dependencies. It uses responsive layouts, keyboard-friendly navigation, and reduced-motion styles.

## Run locally

From the project directory, start a simple local web server:

    python3 -m http.server 8000

Then open http://localhost:8000 in a browser. The site can also be opened directly from `index.html`.

## An intentional approach to AI

The development process highlights a practical way to work with AI: give it useful context, break the work into focused steps, review what it produces, and refine it with specific feedback. ChatGPT supported the workflow; Pranit remained responsible for the direction, review, permissions, and final publishing decisions.
